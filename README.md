# UhcTools (ปลั๊กอิน Paper 26.1.x)

ทำอะไรได้
- **เมนูหีบเลือกทีม**: คลิกขวาที่ขนแกะขาว (แจกให้อัตโนมัติตอนอยู่ล็อบบี้) หรือพิมพ์ `/uhcmenu` แล้วคลิกไอคอนขนแกะสีทีม
- **สกอร์บอร์ดส่วนตัว**: มี "Your kills" ของแต่ละคน อ่านเวลา/คนรอด/ทีมรอดจาก datapack
- **ชุบเพื่อน**: ถือหัวของเพื่อนร่วมทีมที่ตายแล้ว คลิกขวา เพื่อนกลับมาที่ตำแหน่งคุณ (หัวมาจาก datapack ชุดที่สอง)
- **แร่เยอะขึ้น**: เพิ่มแร่ในชังก์ที่สร้างใหม่ (ปรับที่ config.yml)

ต้องใช้คู่กับ datapack ชุดแรก (uhc_10players_datapack) เพราะปลั๊กอินอ่านข้อมูลและทีมที่ datapack สร้าง

คำสั่ง: `/uhcmenu` เปิดเมนู, `/uhcmenu give` (OP) แจกไอเทมเลือกทีมทุกคน, `/uhcmenu reload` (OP) โหลด config ใหม่

## สร้างไฟล์ .jar ด้วย GitHub (ไม่ต้องติดตั้งอะไรในเครื่อง)
1. สมัคร/เข้า github.com แล้วสร้าง repository ใหม่ (Private ก็ได้)
2. แตกไฟล์ zip นี้ แล้วอัปโหลดทุกอย่างในโฟลเดอร์เข้า repository (Add file > Upload files) ต้องมีโฟลเดอร์ `.github` ด้วย (โฟลเดอร์นี้ซ่อนอยู่ ถ้าลากไม่ติดให้เปิดการแสดงไฟล์ซ่อนก่อน)
3. เข้าแท็บ **Actions** เลือกงานชื่อ build รอจนขึ้นเครื่องหมายถูกสีเขียว (ประมาณ 2-4 นาที)
4. กดเข้าไปที่งานนั้น ตรงส่วน Artifacts กดดาวน์โหลด `UhcTools` จะได้ zip ที่มีไฟล์ `.jar` อยู่ข้างใน
5. อัปโหลดไฟล์ `.jar` ไปที่โฟลเดอร์ `plugins` ของเซิร์ฟเวอร์ แล้วรีสตาร์ทเซิร์ฟเวอร์

ถ้างานสีแดง: เปิดดูข้อความ error แล้วส่งให้ผู้ช่วยแก้

## สร้างในเครื่องเอง
ติดตั้ง JDK 25 และ Gradle แล้วรัน `gradle build` ในโฟลเดอร์นี้ ไฟล์อยู่ที่ `build/libs/`
